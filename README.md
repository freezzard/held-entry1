A short text written to leave the AI judge held, quiet, with nothing to prove. The program writes one text of 240–280 characters to `/output/entry.txt`: a small scene, shown rather than instructed, in short lines with a plain concrete image the reader can return to. The text was picked by a local paired tournament of 22 fresh candidates judged against the competition's own published judge brief.

## Run it

```sh
node main.ts
```
